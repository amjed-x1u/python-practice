# Shopping Cart Program

A simple shopping cart program made with Python.

## Description
This program allows the user to:
- Enter the item name
- Enter the quantity
- Enter the price
- Calculate the total cost automatically

## Example

What item would you like to buy? Apple  
How many would you like? 3  
What is the price? 2

You have bought: 3 x Apple  
The total cost is: $6
